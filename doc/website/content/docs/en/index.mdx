Welcome to the **NexusData** docs. This site is bilingual (EN/TR) and marks every page with a status badge.

<Callout tone="note" title="Phase 4 content">
Getting started, core concepts, and source readers are documented against **v1.0** public headers. Optional CMake features are flagged on their pages.
</Callout>

## Pipeline

`Source → Dataset → Sampler → DataLoader → Batch → NDArray`

NexusData prepares and delivers data. It does **not** implement matmul, backprop, models, optimizers, or training loops.
