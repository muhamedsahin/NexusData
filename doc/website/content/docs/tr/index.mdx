## Boru hattı

`Source → Dataset → Sampler → DataLoader → Batch → NDArray`

NexusData veriyi hazırlar ve teslim eder; matmul, backprop, model veya training loop **içermez**.

<Callout tone="note" title="Opsiyonel backend'ler">
Parquet, SQLite ve HDF5 için ilgili CMake bayrakları gerekir (`NEXUSDATA_WITH_ARROW`, `NEXUSDATA_WITH_SQLITE`, `NEXUSDATA_WITH_HDF5`).
</Callout>
