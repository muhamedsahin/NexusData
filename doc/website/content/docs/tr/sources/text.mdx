## TextLineDataset (map-style)

Tüm satırları belleğe yükler (**TextDataset** akışı için map-style giriş noktası):

```cpp
TextOptions opt;
opt.max_length = 512;   // 0 = sınırsız
opt.skip_empty = true;

TextLineDataset lines("corpus.txt", opt);
Sample s = lines.get(0);
// input: UInt8 UTF-8 baytları [L]
// label: demo denetimi için satır indeksi (skaler)
```

| Alan | Etki |
| --- | --- |
| `max_length` | Uzun satırları kes |
| `skip_empty` | Yüklemede boş satırları at |

Değişken uzunlukta batch'ler için [collate_pad_sequence](/docs/concepts/batch-collate) ile eşleştirin.

## TextLineIterable (streaming)

Tüm dosyayı **yüklemez**:

```cpp
TextLineIterable stream("huge.log", opt);
auto it = stream.make_iterator();
while (it->has_next()) {
  Sample s = it->next();
}
```

ETL veya özel eğitim döngüleri için kullanın. Map-style `DataLoader` `Dataset` bekler — standart batch için sarmalayın veya buffer'layın.

## Tokenizer'lar (yalnızca C++)

```cpp
WhitespaceHashTokenizer tok(/*vocab_size=*/10000);
auto ids = tok.encode("merhaba dunya");
```

`Tokenizer` soyut bir C++ arayüzüdür; model ağırlığı taşımaz. Hazır türler `WhitespaceHashTokenizer`, `BpeTokenizer` (vocab dosyası ve merges dosyası), `WordPieceTokenizer` ve `UnigramTokenizer` olur.

Nexus Python kabuğu bu türleri çağırmaz. Python paketi bunları sunmaz. `nexusdata_py` de sunmaz. Bkz. [Python bağları](/docs/integration/python-bindings).
