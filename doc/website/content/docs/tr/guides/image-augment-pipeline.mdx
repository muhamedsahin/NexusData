```cpp
#include "nexusdata/nexusdata.hpp"
using namespace nexusdata;

auto raw = std::make_shared<ImageFolder>("data/train");
auto tfm = std::make_shared<Compose>(std::initializer_list<TransformConstPtr>{
    std::make_shared<RandomHorizontalFlip>(0.5f, 7),
    std::make_shared<Resize>(256, 256),
    std::make_shared<CenterCrop>(224, 224),
    std::make_shared<ToTensor>(),
});
MapDataset ds(raw, tfm);

DataLoaderOptions lo;
lo.batch_size = 32;
lo.shuffle = true;
lo.seed = 1;
DataLoader loader(std::move(ds), lo);
```

Batch içindeki tüm tensörler dönüşümden sonra aynı CHW şeklinde olmalıdır. Sınıf adı `ImageFolder`'dır.

Tek dosya çözümü `load_image` ile `resize_hwc_u8` veya `resize_to_chw_f32` kullanır. PNG, JPEG ve BMP yazmak C++ fonksiyonu değildir; Python kabuğundaki `nexus.data.save_image` bunu yapar. Bkz. [Görsel klasörü](/docs/examples/images).
