NexusData MatrixFlash başlıklarını **içermez**. `MatrixFlashAdapter` yalnızca görünüm üretir.

Opsiyonel `-DNEXUSDATA_WITH_MATRIXFLASH=ON` ileride daha zengin bağlama için SDK bağlantısı bildirir.
