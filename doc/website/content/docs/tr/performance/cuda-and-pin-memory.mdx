CMake: `-DNEXUSDATA_WITH_CUDA=ON`. CUDA **yalnızca veri hazırlama / transfer** içindir; eğitim matematiği yoktur.

```cpp
lo.pin_memory = true;
lo.device = Device::cuda(0);
```

GPU RNG: Philox. Host: PCG32. Bkz. [Determinizm](/docs/concepts/determinism).
